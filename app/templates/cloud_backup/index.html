About Cloud Backups

Cloud backups copy your local data/backups/ folder to your configured S3-compatible provider. Run a local backup first, then use Run Now to push it to the cloud. You can also schedule automated cloud backups from the Scheduled Tasks page using the Cloud Backup task type.

Supported providers: Backblaze B2, AWS S3, Cloudflare R2, MinIO, and any S3-compatible endpoint.
